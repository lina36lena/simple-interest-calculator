
# Simple Interest Calculator

This project is a simple interest calculator
that calculates simple interest based on
the principal amount, interest rate, and time.

## Description

The calculator uses the following formula:

Simple Interest = (P * R * T) / 100

Where:
- P = Principal amount
- R = Annual interest rate
- T = Time in years

## Example

Principal: 1000
Annual Interest Rate: 5%
Time: 2 years

Simple Interest = (1000 * 5 * 2) / 100 = 100

## Features

- Easy to use
- Calculates simple interest
- Uses principal, rate, and time
- Simple Bash implementation
