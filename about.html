Who We Are

Simple Interest Calculator is a student web development project created by Alina. Our goal is to make simple interest calculations easy and accessible.

Our Mission

Our mission is to provide a simple and user-friendly tool for calculating interest. We also aim to improve our programming and web development skills.

Team Guidelines

Team members should follow these guidelines when contributing to the project:

  • Write clean and readable code.
  • Use GitHub to track project changes.
  • Test new features before submitting them.
  • Document important changes.
  • Communicate respectfully with contributors.
  • Report bugs and suggest improvements.

How to Contribute

Contributors can fork the repository, create a new branch, make improvements, and submit a pull request.

Please read our CONTRIBUTING.md and CODE_OF_CONDUCT.md files before contributing.
